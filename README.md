# Atelier Portfolio Template

A static portfolio template for designers and photographers.

A warm editorial layout with big type, rounded cards and playful motion. Built with pure HTML plus CSS plus vanilla JS. No frameworks. No external images. All art is CSS shapes plus inline SVG.

## How To Run

1. Open a terminal in this folder
2. Run `python3 -m http.server 8000`
3. Visit http://localhost:8000 in a browser

You can also open `index.html` directly with no server.

## Features

1. Sticky nav with mobile menu plus smooth scroll plus active link glow
2. Hero with oversize type plus CSS portrait card plus skills marquee
3. Works grid with category filters plus preview modal plus hover zoom
4. About plus services plus experience timeline with scroll reveal
5. Contact form with validation plus success note plus footer, fully responsive

## Files

1. `index.html` Structure and copy for all sections
2. `styles.css` All visual style plus layout plus responsive rules
3. `script.js` Menu plus filters plus modal plus reveal plus form logic
4. `README.md` This guide

## Palette

Paper `#FAF7F2` plus Ink `#1A1A1A` plus Terracotta `#E85D3D` plus Sage plus Moss plus Gold. Solid colors only.

## Notes

No build step. No external images. Works offline once opened. Edit copy in `index.html` and tune color in `styles.css`.
